## 🎯 The STAR Method (Use for EVERY behavioral answer)

```
S — Situation: Set the context (project, team, timeline)
T — Task: What was YOUR responsibility?
A — Action: What did YOU specifically do?
R — Result: What was the measurable outcome?
```

# SECTION 8: SITUATIONAL/SCENARIO QUESTIONS (Q86–Q100)

## 86. What if your test finds a bug but the developer disagrees?

## 88. What if the requirement changes mid-sprint?

> "Assess impact on existing tests, communicate effort needed, update test cases, and adjust sprint scope with the team. Change is normal in agile — the key is managing it transparently."

## 89. What if you're assigned a technology you've never used?

> "I'd spend 2-3 days learning fundamentals (docs, tutorials, YouTube), build a small POC, ask experienced colleagues for tips, then start contributing. I've done this multiple times — most recently with SSE streaming and LLM testing."

---

## 90. What if the build is consistently failing?

## 91. What if your manager asks you to do something unethical?
