# 🐍 Learn Python With Your Own Project

Welcome! This is a **step-by-step Python course built entirely around your real project** —
the `agentic-ai-service-backend` (a FastAPI service for multi-tenant AI agent orchestration
using LangGraph + LangChain + AWS Bedrock).

Instead of learning with toy examples, every concept here is tied to **actual code from your
repository**, so you learn Python *and* understand your project at the same time.

---

## 🎯 How to use this course

1. Go through the lessons **in order** (01 → 10). Each builds on the previous one.
2. Every lesson has the same 5 sections:
   - **📖 Concept** — a short, plain-English explanation.
   - **🔎 In Your Project** — real code from your repo that uses the concept.
   - **🏋️ Exercise** — a small challenge to try yourself.
   - **🔗 Project Connection** — why this matters for *your* codebase.
   - **➡️ Next Step** — what to learn next.
3. Actually **type the code** yourself. Don't copy-paste. Muscle memory matters.
4. Keep a scratch file `learn-python/playground.py` to experiment.

## 🧭 Suggested pace

- **Week 1:** Lessons 00–03 (fundamentals)
- **Week 2:** Lessons 04–06 (functions & OOP)
- **Week 3:** Lessons 07–09 (errors, files, frameworks)
- **Week 4:** Lesson 10 (build something real in the project)

Adjust freely — go faster or slower based on how comfortable you feel. If a lesson feels
too easy, skim it and do the exercise. If it feels hard, re-read the **Concept** and retype
the **In Your Project** examples.

---

## ✅ Before you start — quick self-check

Rate yourself 1–5 on each. This helps you know where to focus:

- [ ] I can run a Python file from the terminal.
- [ ] I understand variables and basic types (`int`, `str`, `list`).
- [ ] I've written an `if` statement and a `for` loop.
- [ ] I've written my own function.
- [ ] I understand what a class is.
- [ ] I've used a library someone else wrote.

Wherever you scored low, spend extra time on that lesson. Let's go! 🚀
